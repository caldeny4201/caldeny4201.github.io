## Live Projects

### [Fathom — CS Study Library](https://caldeny4201.github.io/fathom/)
A single-page study platform covering 71 topics across 9 South African universities.

- **Stack:** Vanilla HTML/CSS/JS, hash routing, data-driven rendering
- **Features:** Search, filter by discipline/year/university, dark mode, mobile responsive
- **What it demonstrates:** Data modelling for many-to-many relationships, no-framework architecture, design systems

### [Voltguard Electrical](https://caldeny4201.github.io/voltguard/)
A fixed-price electrical services site for a Sandton-based business.

- **Stack:** Vanilla HTML/CSS
- **Features:** Service directory, rate cards, membership tiers, conversion-focused copy
- **What it demonstrates:** Information architecture, brand positioning, business-model thinking

### [LexPilot — Legal Practice Management Prototype](https://caldeny4201.github.io/lexPilotInvoicer/)
Working front-end for a legal billing and trust account system. Not production-ready — prototype only.

- **Stack:** Vanilla JS, complex state management, REST API stubs
- **Features:** Trust account logic, VAT calculation, shortfall detection, invoice generation, PayFast integration stubs, admin dashboard with Chart.js and FullCalendar
- **What it demonstrates:** Domain modelling for regulated industries, state management, business logic
